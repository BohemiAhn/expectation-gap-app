키 발급 방법

  1. 아래 Google AI Studio 바로가기 클릭 (구글 계정 로그인 필요)
  2. "Create API key" 버튼 클릭
  3. 기존 프로젝트 선택 또는 새 프로젝트 생성 후 발급
  4. 생성된 키(AIza로 시작)를 복사해 아래 칸에 붙여넣기

무료로 발급 가능하며, 발급 즉시 사용할 수 있습니다. 키는 절대 다른 사람과 공유하지 마세요.
